================================================================================
TROUBLESHOOTING
================================================================================

Issue: "Error validating your PunchOut request"
-----------------------------------------------
- Verify SharedSecret matches: "response_secret"
- Check XML has all required fields: Identity, BuyerCookie, BrowserFormPost URL
- Ensure Content-Type is application/x-www-form-urlencoded
- Verify key name is exactly "cxml-urlencoded"

Issue: No logs in terminal
---------------------------
- Confirm server is running: python manage.py runserver
- Check URL is correct: http://127.0.0.1:8000/punchout/setup/
- Verify POST method is selected
- Look for "Forbidden (403)" - might be CSRF issue (should be exempt)

Issue: Products not found (edit mode)
--------------------------------------
- Check product codes exist in database
- Verify exact match: Product.objects.filter(item_code='N69PC-001-0026')
- Use actual product codes from your database

Issue: Webhook.site shows nothing
----------------------------------
- Check if webhook URL is correct in XML
- Verify auto-submit form rendered (check Postman response)
- Look for JavaScript errors in browser console
- Check if webhook.site session expired (generate new URL)
